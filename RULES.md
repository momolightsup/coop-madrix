# Project Operating Rules & Safety Guidelines

These rules govern all interactions, coding tasks, and execution within the **Coop Madrix** project.

---

### 1. Safety & System Integrity Check
- **Pre-execution Verification**: Prior to executing any prompt, shell command, or script, thoroughly verify that it is safe and will not cause damage, harm, or instability to the computer, operating system, or existing files.
- **Harmless Execution**: Avoid any commands or actions that touch system files, modify environment-level registry/settings, or risk data corruption.

### 2. Strict File Retention & Storage Scope
- **Zero Deletions**: Do not delete existing files. If files need replacement, update them in-place or preserve backups/history without deleting previous work.
- **Confined to Project Folder**: All project code, assets, data, and configurations must be saved inside the project directory:  
  `c:\Users\monik\OneDrive\Dokumente\Projects\Coop Madrix`.

### 3. Planning & Explicit Permission
- **Structured Plan First**: Before executing any major chunk of programming work, architectural change, or component implementation, present a detailed plan.
- **Permission Required**: Ask for explicit confirmation and user permission before writing the code or running the setup.

### 4. Time & Effort Estimation
- **Time Estimates Included**: Every proposal must include an estimated timeframe / duration (e.g., minutes/hours) indicating approximately how much time the task will require.
